Помощник для определения дополнительных ремонтных услуг в объявлении и подготовки фактических черновиков.

## Что выяснили

- Train: 10 000 строк, 4 855 уникальных описаний после нормализации регистра/пробелов. Метки автоматические, потенциально ошибочные.
- Public-test: 208 строк; 24 пересекаются с train после нормализации. Исходного `mcId` нет. Назначение набора требует уточнения.
- Подготовлены 50 development и 50 control, все `provisional`. Из обучения baseline исключаются все их группы: 363 строки; остаётся 9 637.
- Подготовлены 17 синтетических проверок; два пакетных случая ожидают решения организаторов.

## Локальное воспроизведение

Нужны Python 3.12 и исходный ZIP, который в Git не включён. Из корня проекта в PowerShell:

```powershell
python -m pip install --target .tools/python --no-cache-dir --no-deps -r requirements-stage1.txt
python scripts/audit_data.py --archive 'C:/Users/Admin/Downloads/innoglobalhack_avito(1).zip'
python scripts/prepare_review.py --archive 'C:/Users/Admin/Downloads/innoglobalhack_avito(1).zip'
python scripts/prepare_review.py --archive 'C:/Users/Admin/Downloads/innoglobalhack_avito(1).zip' --verify
```

При первом запуске выборки создаются; повторный запуск проверяет их и отказывается перезаписывать отличающиеся файлы. Для обучения использовать `training_exclusions_manifest.jsonl`: прежний флаг `excluded_from_training` в исходном манифесте учитывал только control.

Исходный датасет, локальные выборки, манифесты, зависимости и временные материалы не публикуются. Подготовку можно воспроизвести из ZIP; human-review хранится отдельно от замороженных исходных примеров.
