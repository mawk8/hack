# Avito Drafts

Из объявления «Ремонт под ключ» (101) выделяем услуги 102–106 и создаём черновики для проверки человеком.

**Статус:** код прототипа и baseline проверены; реальный запуск LLM на GPU и итоговая оценка ещё впереди.

## С чего начать

1. [Актуальный план](docs/PLAN.md) — порядок задач, эксперименты и как отмечать результат.
2. [Статус и измерения](docs/STATUS.md) — что действительно выполнено.
3. [Запуск](docs/LOCAL_RUN.md) · [Команды экспериментов](docs/EXPERIMENTS.md).

Агенту: сначала прочитать [AGENTS.md](AGENTS.md), затем план; не перечитывать весь архив обсуждений.

## Устройство

`description → классификация → черновики → проверка структуры → результат`

| Путь | Содержимое |
|---|---|
| `avito/` | Приложение, классификатор, LLM-клиент и интерфейс |
| `scripts/`, `tests/` | Команды запуска/оценки и проверки |
| `tools/review.html`, `notebooks/` | Ручная разметка и подготовленный GPU-notebook |
| `docs/PLAN.md`, `docs/STATUS.md` | Текущий план и доказанные результаты |
| `docs/stage1/`, `docs/superpowers/plans/`, `output/pdf/` | История исследования; читать только по необходимости |

**Ветки:** `main` — входная страница; `prototype` — рабочий код MVP. После клонирования: `git switch prototype`.

В Git входят код, тесты и необходимые документы. `data/`, `.tools/`, `tmp/`, `.superpowers/`, реальные объявления, ключи, кэши и веса остаются локально. Файлы автоматически не удаляем.
