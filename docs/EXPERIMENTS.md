## Запуск после появления локальной модели

PowerShell, корень проекта. Выполните локальную установку из `docs/LOCAL_RUN.md`: `requirements-prototype.txt` в `.tools/python`. Сервер должен обслуживать alias `avito-qwen3-8b` на `http://127.0.0.1:8080/v1`. API только loopback, прокси отключены, редиректы запрещены, timeout 30 секунд, ответ ограничен 262144 байтами. Платные API не используются.

```powershell
$ExperimentPython = 'python'
$ExperimentArchive = 'ПОЛНЫЙ/ПУТЬ/К/innoglobalhack_avito(1).zip' # замените своим путём

# Приватный пилот: максимум 300, по умолчанию 240, до трёх вариантов на seed.
& $ExperimentPython -X utf8 scripts/generate_synthetic.py --archive $ExperimentArchive --count 240 --output-dir data/runs/synthetic-pilot

# Сначала короткий предварительный прогон A/C. Без доступного alias остановится до обучения.
& $ExperimentPython -X utf8 scripts/compare_experiments.py --archive $ExperimentArchive --limit 5 --output-dir data/runs/comparison-smoke

# Полный A/B/C на одних и тех же 50 development, только после успешного пилота.
& $ExperimentPython -X utf8 scripts/compare_experiments.py --archive $ExperimentArchive --synthetic data/runs/synthetic-pilot/synthetic.jsonl --output-dir data/runs/comparison
```

Все выходные папки должны быть новыми и находиться в игнорируемом `data/`; перезаписи нет. Если путь уже занят, выберите другой, существующие данные сохраняйте. A всегда обучается заново на текущих проверенных 9637 fit-строках тем же `train()`, что B; кэшированные модели не принимаются. Это требует полного времени обучения даже при `--limit`. Без `--synthetic` вариант B отсутствует. Несостоявшийся/пустой пилот и неполный `metadata.json` запрещают обучение B; ручного обхода этого ограничения нет.

## Что сохраняется и проверяется

Генерация берёт только разрешённые fit-строки загрузчика, детерминированно выбирает уникальные нормализованные seeds с seed 42. В промпт попадает полный разрешённый исходник и фиксированная таксономия. Проверяется порядок режимов в каждом батче: `offered`, `negated`, `third_party` (последний неполный батч — начало этой последовательности). Импорт синтетики повторно проверяет этот порядок; однородный пустой батч отвергается. В metadata сохраняются `scenario_counts`. Каждому примеру присваиваются ID, `seed_item_id`, `seed_group_id`, модель, версия и хэш промпта, `status: provisional`. Точные цитаты обязательны для положительных меток. Эти проверки не доказывают семантическую истинность меток.

Дубликаты отбрасываются по SHA256 нормализованных описаний всего исходного train, включая исключённые группы, и самой синтетики. Контрольные тексты не сохраняются и не передаются модели; public-test parquet не читается. Контрольные артефакты загрузчик проверяет как непрозрачные байты по хэшам. При ошибке батча генератор пишет `status: failed` и причину в `metadata.json`, останавливается без выдуманных примеров. Ранее успешные батчи остаются на диске.

Сравнение повторно проверяет происхождение и дубликаты синтетики. A и B используют те же оригинальные строки, без дополнительной дедупликации или весов. B добавляет только синтетику с предварительными метками. Форма `tools/review.html` предназначена для development с `source_mcId/proposed_labels`, а синтетика имеет `mcId/labels`: совместимость с формой для неё не реализована. Возможна отдельная ручная выборочная проверка JSONL без редактирования зафиксированных артефактов; B остаётся provisional/noisy диагностикой.

`A_classification`/`B_classification` — только классификатор. `A_full`/`B_full` включают его время и вызов того же LLM с `forced_categories`; пустой результат классификатора пропускает генерацию. `C_full` — один полный вызов LLM. Предсказания, черновики, ошибки и времена сохраняются в отдельных JSONL, агрегаты — в `metrics.json`.

Ошибочная полная строка имеет `predicted: null` и причину, а не успешный пустой ответ. Все строки остаются в знаменателе; пустой набор для ошибки используется только для подсчёта FN. Метрики: TP/FP/FN, micro-F1, категории 101–106 с маской исходной 101, ошибки на пустых эталонах, failure rate, длительности всех строк и nearest-rank p95, число попыток и доступные token usage. Неизвестное usage отражено через число строк с доступным usage. Сохраняются версии, хэши и покрытие. Один проход не заменяет итоговые повторные измерения; при следующих запусках используйте новые папки. API billing = 0, стоимость оборудования не измерена. Фактичность черновиков автоматически не доказана.

## Человеческая development-разметка

Без overlay результаты подписаны `noisy-label diagnostics; human_verified=0`. Неизменяемый development-файл не редактируют: экспортируют отдельный JSONL в `data/`. `--human-development data/reviews/development-human.jsonl` принимает ровно те же 50 identity/group/source/description, меняются только предлагаемые метки и поля проверки. Каждая строка требует `status: human_verified`, непустой `reviewer`, ISO datetime `reviewed_at` (например `2026-11-14T10:30:00.000Z`) и `evidence: [{"mcId":102,"quote":"точная цитата"}]` для каждой положительной категории. При пустых метках evidence может быть пустым. Проверяются формат и совпадения, а не сам факт добросовестной человеческой работы.

```powershell
& $ExperimentPython -X utf8 scripts/compare_experiments.py --archive $ExperimentArchive --human-development data/reviews/development-human.jsonl --output-dir data/runs/comparison-human
```

Финальный control здесь не запускается. Он требует отдельного оценщика после ручной gold-разметки и заморозки. Подстройка промпта по control недопустима; development-итераций по плану не более трёх.
