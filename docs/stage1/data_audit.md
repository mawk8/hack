Нормализация: `casefold()` → замена каждой последовательности whitespace одним пробелом → `strip()`. Пунктуация, `ё`, Unicode-форма сохраняются. Функция `normalize(text)` доступна для переиспользования из `scripts.audit_data`. Это технический ключ группировки, не доказательство смыслового тождества.

Общие ключи — пересечение множеств описаний. Строки — сумма частот каждого общего ключа в соответствующей выборке; пары — сумма произведений двух частот. Поэтому число пар может превышать число строк. Сырые тексты, метки test, ключи и хеши отдельных объявлений в отчёт не включены.
