# Первый прототип и эксперименты

> Исполнение: Superpowers subagent-driven-development, отдельная проверка каждого пакета; Ponytail full. Пользователь поручил исполнение оставшегося плана и локальное развёртывание 14.11.2026.

**Цель:** работающий полный сценарий description + mcId → дополнительные категории и достоверные черновики, baseline, небольшой эксперимент с синтетикой и воспроизводимые измерения.
**Архитектура:** Python, sklearn baseline; один запрос к локальному llama.cpp, Qwen3-8B Q4_K_M, thinking выключен. Стандартная библиотека для HTTP/CLI и простого локального демо. Раздельные поля evidence/ограничения/черновики внутри одного ответа; внешний JSON только drafts.
**Основание:** docs/stage1/evaluation_protocol.md и docs/stage1/decisions.md. Веса 5/3/2.

## Ограничения и принятые решения
- Все материалы в E:/hackaton, без удаления. Модели, зависимости, входные объявления и подробные ответы только в игнорируемых data/ и .tools/.
- На доступном ПК RTX3050 Laptop 4GB. RTX3060 12GB у товарища; подготовить переносимый запуск и notebook Colab/Kaggle, не выдавать их за выполненный запуск на недоступном GPU.
- Новое поручение разрешает приложение и локальные эксперименты; прежнее ограничение аналитическим этапом снято. Платные API не вызывать без конкретного пилота и оценки стоимости.
- База обучения: все 9637 разрешённых строк, неизменная обработка дублей в сравниваемых вариантах. Контроль и все его группы не использовать для генерации/подбора. Human-review отсутствует: выводы по автометкам только noisy-label диагностика.
- Пилот синтетики 200–300 разнообразных примеров, статусы provisional, отдельная проверка меток; до 2000–3000 расширять лишь при пользе на реальном development. Не копировать dev/control в обучающую синтетику.
- Локальная генерация и пилотные замеры выполняются по доступным ресурсам. Облачные данные не публиковать; notebook предназначен для приватной пользовательской сессии. Не обещать бесплатную GPU-квоту.

## Task 1: baseline и воспроизводимый загрузчик
- [ ] Проверять хэши frozen manifests, исключать все 363 строки; нормализатор из существующего аудита.
- [ ] TF-IDF char_wb 3–5, min_df2, max_features80000, sublinear_tf; OneVsRest LogisticRegression C1 liblinear, random_state42, max_iter1000, threshold0.5. Source101 для baseline: другие source не имеют полного обучающего эталона и отвергаются явно.
- [ ] CLI обучения/оценки development; модель и предсказания локально, агрегаты с версиями, TP/FP/FN, micro-F1, числом примеров, временем и honest label status.
- [ ] Тест исключения групп, source и пустого ответа, проверка манифестов; реальный запуск baseline и независимый review.

## Task 2: локальная LLM и полный сценарий
- [ ] Портативный llama.cpp + закреплённый GGUF и инструкция RTX3060; проверить доступный локальный запуск с частичным offload при необходимости. Notebook для приватного Colab/Kaggle с тем же сервером/моделью.
- [ ] Клиент к localhost /v1/chat/completions, строгий JSON и проверки категории/source/дубликатов/evidence/длины. Полный исходник — данные. Timeout и отказ явные, не пустой drafts.
- [ ] Одно локальное демо: ввод description/source, исходник рядом с результатом, evidence отдельно; API POST /predict. Никакой автопубликации.
- [ ] Реальные smoke/challenge прогоны, замер полного запроса, endpoint health, ошибка сервера, отрицания, injection, переключение source; отдельный review.

## Task 3: синтетика, сравнение и передача команде
- [ ] Приватный pilot синтетики с происхождением, метками/основаниями и проверкой дублей; не называть автоматические проверки человеческими.
- [ ] Сравнить A baseline, B baseline+synthetic, C LLM на одинаковом development. Для полного режима baseline использует тот же генератор по фиксированным предсказанным категориям; учесть его вызов в времени/стоимости. Классификационные диагностические метрики отделить от полного сценария.
- [ ] Не более трёх development-итераций. Второй LLM-проверяющий/few-shot — только если конкретная ошибка оправдывает опыт; не делать весь декартов перебор.
- [ ] Подготовить человеческую разметку, измерения и команды переноса на3060, демо и отчёт. Human labels, GPU товарища и ответы менторов отмечать открытыми до фактических свидетельств.
- [ ] Независимый итоговый review, git commit/push, проверка полного сценария; финальный control только после human_verified разметки и заморозки.

## Приёмка
Контракт из постановки соблюдается; реальные успешные и ошибочные запросы измерены; обучение не видит dev/control; не выдаются вымышленные F1/цены или статусы human_verified. Проверены команды старта и воспроизведения. Заявление о выполнении на RTX3060/в облаке требует вывода именно того запуска. Цель остаётся активной, пока требуемые реальные проверки и внешний человеческий этап не завершены.
