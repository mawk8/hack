# Состояние прототипа — 14 ноября 2026

## К чему пришли

Оценка 5/3/2. Первый кандидат — один локальный LLM-вызов с логически раздельными выбором услуг и написанием черновиков. Код проверяет формат, категории, source, повторы и присутствие цитат. Эти проверки не гарантируют смысловую достоверность. Второй LLM-вызов и гибридная маршрутизация требуют измеренной пользы.

Ponytail используется для минимального кода на стандартной библиотеке, Superpowers — для задач с независимым review. Агенты помогают разрабатывать и проверять решение; в самом продукте постоянной команды агентов нет.

## GPU и облако

На текущем компьютере обнаружена RTX 3050 Laptop 4GB. RTX 3060 12GB находится у товарища, доступа к его ПК нет. Для неё выбран проверяемый кандидат Qwen3-8B Q4_K_M (~5 ГБ GGUF), закреплены ревизия и SHA256. Подготовлены локальный installer/start script и приватный notebook для Colab/Kaggle. Установку бинарного runtime и реальный модельный запуск выполнить здесь пока не удалось: запрос доступа к скачиванию был отклонён. Самостоятельно обходить это ограничение не будем.

Пользователь подтвердил Windows на ПК товарища. Приложение фактически запущено через CLI в проверке: health и страница вернули 200, отсутствие модели — 503 model_unavailable, без успешного пустого drafts. Подробные команды экспериментов — `docs/EXPERIMENTS.md`.

Установщик проверен на файловых фикстурах: хэши, отказ от перезаписи, защита путей ZIP. Ячейки notebook компилируются, но реальный запуск в облаке ещё не выполнен. Доступность GPU и квоты не обещана. Инструкция — `docs/LOCAL_RUN.md`.

## Что остаётся

1. Запустить runtime и модель на 3060 товарища либо в приватной облачной сессии, получить health и реальный smoke-ответ. Пока нет свидетельства такого запуска.
2. Измерить реальные полные LLM-ответы; синтетические HTTP-фикстуры проверяют интеграцию, не качество модели.
3. Вручную проверить 50 development и 50 control. Форма `tools/review.html` работает локально и сохраняет отдельные файлы. Статусы human_verified выставляет человек после проверки; агент их не подделывает.
4. Сгенерировать небольшой проверяемый пилот 200–300 примеров из разрешённых training seeds, проверить метки и сравнить baseline A/B на реальном development. До 2000–3000 расширять только после пользы; не учить на dev/control и их производных.
5. Измерить LLM и полный baseline+генератор, фактичность, ошибки, время и расход токенов. Затем ограниченные development-итерации, заморозка и один финальный human-verified control.
6. Получить ответы о пакетах/партнёрах, source во входе и категории для live-генерации; уточнить точное время и формат сдачи 16 ноября. Подготовить полное демо и воспроизводимый запуск.

Приёмка программной части: независимые review приняты; скрипт сравнения всегда переобучает A и B на единой разрешённой основе, однородный пустой synthetic-пилот отвергается, дата human-review совместима с формой. Отдельно проверяются ошибки и полный знаменатель метрик. Это не свидетельство выполнения самого эксперимента.

Цель ещё не завершена: baseline — реальный результат; LLM-сравнение, синтетический пилот и финальная человеческая проверка остаются впереди. Платные API не вызывались, API-бюджет не расходовался. Первое необходимое внешнее действие — запуск модели на 3060 по `docs/LOCAL_RUN.md` (либо новое явное разрешение скачивания здесь); затем приватные данные и ручная проверка по протоколу.

Итоговый совместный прогон: **25 тестов, 20,564 с, exit 0**. Это unit/HTTP-fixture и интеграционные проверки кода; реального GPU-качества они не измеряют.
