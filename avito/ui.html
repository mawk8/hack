Дополнительные услуги ремонта

Объявление → найденные услуги → ваш выбор → черновики. Публикация выполняется пользователем отдельно.

Исходное объявление

Исходная категория: 101 — Ремонт под ключ

Или таблица CSV

UTF-8 / BOM, разделитель: запятая, точка с запятой или табуляция. До 200 записей, до 2 MiB. Колонки: description (обязательно), id или testcase, title (необязательно). Без колонки идентификатора используется номер записи. title только показывается, в модель передаётся description.

Команды внутри объявления рассматриваются как данные. Строки обрабатываются последовательно локальной моделью.

Результат

Введите объявление или выберите CSV.

Фактичность нужно проверить по исходнику. Точная цитата не подтверждает смысл автоматически. Отметьте услуги для черновиков; автоматическое обнаружение сохранится отдельно от выбора.
